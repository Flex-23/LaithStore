# تقنيتي — متجر إلكتروني عصري

واجهة متجر ولوحة تحكم إدارية جاهزة للإنتاج، مبنية بـ **Next.js 16 (App Router)**،
**TypeScript**، **Tailwind CSS v4**، **Prisma ORM**، **MySQL** (XAMPP محلياً) و **Zod**.

- واجهة عربية بالكامل (RTL) بخطوط Cairo/Tajawal، هوية تركواز `#2A99A3` + وردي `#F28DA0`، وضع فاتح/داكن وسلة محفوظة
- العملة بالدينار العراقي (`د.ع`) والأرقام إنجليزية مع فواصل الآلاف (`125,000 د.ع`)
- صور المنتجات والفئات: عبر **رابط** أو **رفع من الجهاز** (تُحفظ في `public/uploads`)
- مصادقة آمنة للعملاء والإدارة (كلمات مرور مشفّرة، كوكي جلسة موقّع)
- لوحة تحكم كاملة: الكتالوج، المخزون، الطلبات، وتحليلات المبيعات
- الطلبات تُنقص المخزون ذرّياً داخل معاملة Prisma واحدة

---

## المتطلبات

- **Node.js 20+** (تم التطوير على Node 24)
- **XAMPP** مع MySQL يعمل على `localhost:3306`

## البدء السريع

```bash
# 1) تثبيت الحزم
npm install

# 2) شغّل MySQL من لوحة تحكم XAMPP

# 3) أنشئ المخطط وحمّل البيانات التجريبية (ينشئ قاعدة `store_db`)
npm run db:setup      # = prisma db push && prisma db seed

# 4) شغّل التطبيق
npm run dev           # http://localhost:3000
```

> ملاحظة: `db:seed` يستبدل الكتالوج (الفئات والمنتجات والطلبات) بالكامل
> بالبيانات العربية التجريبية، ويبقي على حسابات المستخدمين.

### متغيرات البيئة

الإعدادات في `.env` (مضبوطة مسبقاً لإعدادات XAMPP الافتراضية):

```env
DATABASE_URL="mysql://root:@localhost:3306/store_db"
AUTH_SECRET="dev-secret-change-me-please-32chars-min"
```

غيّر `AUTH_SECRET` قبل النشر.

## الحسابات والدخول

| الدور | الهاتف        | كلمة المرور | صفحة الدخول    |
| ----- | ------------- | ----------- | -------------- |
| مدير  | `07700000000` | `admin1234` | `/admin/login` |
| مندوب | `07722222222` | `agent1234` | `/admin/login` |
| زبون  | `07711111111` | `user1234`  | `/login`       |

الدخول **منفصل تماماً** بين الزبائن والإدارة:

- **الزبائن**: `/register` لإنشاء حساب و`/login` للدخول. حسابات الإدارة تُرفض هنا.
- **الإدارة (المدير والمندوبون)**: `/admin/login` فقط — لا يوجد رابط له من المتجر،
  ولا إنشاء حساب ذاتي. حساب المدير يُنشأ عبر البذور (`npm run db:seed`)؛ لتغيير
  رقمه أو كلمة مروره عدّل `prisma/seed.mts` أو استخدم `npm run db:studio`.
  المندوبون يُنشئهم المدير من صفحة **المندوبون**.
- الجلسة كوكي واحد موقّع يحمل الدور؛ الصلاحيات تُقرأ من قاعدة البيانات عند كل
  طلب داخل `/admin/*`، وصفحة الدفع وإنشاء الطلبات تتحقق من دور `USER`.

## المندوبون والصلاحيات

- يُنشئ المدير المندوب باسم ورقم هاتف وكلمة مرور، فيحصل تلقائياً على رقم تسلسلي
  (`AG-0001`، `AG-0002`…) و**أجر ثابت لكل طلب** (مثل 2,000 د.ع).
- الصلاحيات الأربع: **المنتجات والفئات**، **جميع الطلبات**، **لوحة التحكم**،
  **محتوى الصفحة الرئيسية**. القائمة الجانبية والصفحات و Server Actions كلها
  تتحقق من الصلاحية؛ المندوب بلا صلاحيات يرى صفحة «لا توجد صلاحيات».
- **إسناد الطلبات**: يُسند الطلب للمندوب تلقائياً عند أول تغيير حالة يجريه أو
  بزر «استلام الطلب»، ويمكن للمدير تعيين/تغيير المندوب من قائمة على كل طلب.
  الأجر يُثبَّت على الطلب وقت الإسناد فلا تتأثر الأرقام القديمة بتغييره لاحقاً.
- **احتساب الأجر**: على الطلبات **المُخرَجة** فقط (تم الشحن أو تم التوصيل)؛
  الملغاة والمنتظرة لا تُحتسب.
- **صفحة المندوبين** (`/admin/agents`): جدول بالأساسيات (الاسم، الرقم، الأجر،
  الحالة، الإجراءات) وزر **تفاصيل** يفتح `/admin/agents/<id>`: بياناته وصلاحياته،
  طلباته، إجمالي المبيعات، الأجر المستحق، المصروف له، صافي المستحق له، وصافي المتجر.
- **تقارير المندوبين** (`/admin/agents/reports`) و**الصرفيات** (`/admin/expenses`)
  تعرض **الشهر الحالي** افتراضياً وتبدأ من الصفر مع كل شهر عمل جديد؛ الأشهر
  السابقة تبقى في قائمة **الأرشيف** (`?month=YYYY-MM`) ولا يُحذف شيء.
  خيار «كل الفترات» يعرض الإجمالي التراكمي.
- **الصرفيات**: مبلغ + لمن صُرف (مندوب من القائمة أو اسم حر) + ملاحظة.
  ما يُصرف لمندوب يظهر في تقريره ويُخصم من المستحق له.
- **التقارير** (`/admin/reports`): يومي/شهري، والنقر على يوم يعرض ملخصه وطلباته،
  والنقر على شهر يعرض أيامه ثم كل يوم.
- **محتوى الصفحة الرئيسية** (`/admin/home`): نصوص وصور الهيرو والبانر الترويجي.

## المزايا

**المتجر**

- صفحة رئيسية بعرض الفئات والمنتجات مجمّعة حسب الفئة (5 لكل فئة مع رابط **عرض الكل**)
- بطاقات منتجات بشارات الخصم وتنبيه المخزون المنخفض وزر الإضافة للسلة
- سلة منزلقة + صفحة سلة كاملة (محفوظة في localStorage)
- إتمام الطلب يعتمد على بيانات العميل من ملفه (الاسم، الهاتف، المحافظة) — الدفع عند الاستلام
- التوصيل: مجاني فوق 100,000 د.ع وإلا 5,000 د.ع (`lib/constants.ts`)

**الإدارة (`/admin`)**

- لوحة تحكم بالإيرادات والطلبات والمخزون والأكثر مبيعاً
- إدارة المنتجات: الصورة (رابط أو رفع من الجهاز)، السعر، المخزون، وتفعيل الخصم
- إدارة الفئات (بنفس خيارَي الصورة)
- إدارة الطلبات مع بيانات العميل وتغيير الحالة وإسناد المندوب
- تقارير: يومي/شهري، الأكثر مبيعاً، تنبيهات المخزون، وتقارير المندوبين
- المندوبون (صلاحيات ونسب)، الصرفيات، ومحتوى الصفحة الرئيسية

**رفع الصور**

- الصيغ المدعومة: JPG، PNG، WebP، GIF، AVIF — بحد أقصى 4 ميغابايت
- تُحفظ في `public/uploads/` وتُقدَّم على `/uploads/<اسم>`؛ المجلد مستثنى من Git
- حد حجم طلب Server Actions مضبوط على 5MB في `next.config.ts`

**مسارات API**

- `GET /api/health` – فحص الاتصال بقاعدة البيانات
- `GET /api/products` – قائمة المنتجات (`?categoryId=` للتصفية)
- `GET /api/categories` – قائمة الفئات

## التقنيات والبنية

- **App Router** بفصل واضح بين مكوّنات الخادم والعميل
- **Server Actions** للمصادقة وتعديلات الكتالوج وإنشاء الطلبات
- نماذج **Prisma**: `User` (USER/ADMIN/AGENT)، `Category`، `Product`، `Order`،
  `OrderItem`، `Expense`، `HomeContent`
- مخططات **Zod** تتحقق من كل نموذج ومدخلات Server Actions (رسائل عربية)
- القراءات آمنة الفشل: إن كانت MySQL غير متاحة تعرض الصفحات إرشادات الإعداد بدل الانهيار

### بنية المشروع

```
app/
  (storefront)/        # المتجر العام: الرئيسية، المنتجات، الفئة، السلة، الدفع
  (auth)/              # دخول وتسجيل الزبائن
  admin/
    login/             # دخول المدير (منفصل)
    (panel)/           # لوحة التحكم، المنتجات، الفئات، الطلبات، التقارير،
                       # المندوبون (+تقاريرهم)، الصرفيات، الصفحة الرئيسية
  actions/             # Server Actions (المصادقة، الطلبات، الإدارة، المندوبون، الصرفيات، الرئيسية)
  api/                 # Route Handlers
components/            # الشريط العلوي، السلة، بطاقة المنتج، واجهة الإدارة، مزوّدات …
lib/                   # prisma, auth, permissions, agent, zod-schemas, data, format, upload, business-day
prisma/                # schema.prisma + seed.mts
public/uploads/        # الصور المرفوعة من لوحة الإدارة (خارج Git)
```
